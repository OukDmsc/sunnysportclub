# Staff and player photos

Put photos of coaches, players and staff in this folder.

- Recommended format: PNG, JPG or WebP.
- Recommended size: 600 x 600 pixels (square works best).
- Keep each file under 2 MB.

After adding a file, open `data/staff.js` and set the `photo` field to its path:

```js
photo: "assets/photos/alex-morgan.jpg",
```

The file name is case-sensitive on some systems, so match it exactly.
