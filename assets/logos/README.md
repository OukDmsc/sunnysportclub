# Team logos

Put club and team logos in this folder.

- Recommended format: square PNG, SVG or WebP.
- Recommended size: at least 256 x 256 pixels.
- Keep each file under 1 MB.

After adding a file, open `data/teams.js` and set the `logo` field to its path:

```js
logo: "assets/logos/senior-fc.png",
```

The file name is case-sensitive on some systems, so match it exactly.
